hitman

The Open Source API testing and load testing tool

Welcome to hitman

hitman is a powerful and intuitive tool designed to help you perform API testing and simple load testing with ease. As an open-source solution, it is freely available for developers worldwide.

Features

  • Design, test, and validate API requests with ease.
  • Built-in load testing for constant and ramp-up scenarios.
  • Dynamic post-request scripting support.
  • Detailed results with metrics and 90th percentile analysis.
  • Multiple profile support.
